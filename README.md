# Threadform Studio for Windows

[Download Threadform Studio 0.3.0-alpha.3](https://github.com/Beowxlf/threadform-studio-downloads/releases/tag/desktop-v0.3.0-alpha.3)

Download the Windows x64 Setup.exe from the release, run it, then open Threadform Studio from the Start menu. No GitHub account is required.

Version 0.3.0-alpha.3 adds five feminine mannequin body types: Balanced, Straight, Hourglass, Pear and Full. Open **Preview > Mannequin body type**, then **Fine-tune body & fabric** to adjust individual proportions and finish. A new Blender-authored sweater surface follows the body. Independent draggable patterns, individual motif editing, saved color schemes, three poses, zoom and matching PDF/HTML photography remain available.

The suggested workflow is **Brief > Materials > Shape > Pattern > Preview > Publish**. Every stage stays accessible. The interface keeps its baby blue, sage green and cream colors and loading indicators tied to actual work.

## Updates

In version 0.2.0-alpha.3 or later, open **App updates > Check for updates > Download update > Save, install & restart**. Updates are publicly available and signature-verified, with no account or access token. The app saves a recovery copy before installation.

If you have 0.2.0-alpha.1 or earlier, install the new EXE once to switch from the private update channel. Export a .tfstudio backup first. Your exported project files stay in place.

Design work remains offline. Update checks happen only when requested; there are no automatic installations or project uploads. Source code remains private.

This is an engineering alpha. Mannequin proportions, garment envelopes and accessory folds illustrate styling rather than physical fit. Some sweater-side texture distortion remains. The adult mesh and rig are bundled locally under CC0. Body styling does not change knitting measurements or instructions. The Blender development workflow does not add an arbitrary Blender-file import button. Custom dress-form presentation places the first two physical panels; remaining panels stay separate. Patterns need test knitting and technical review. The updater verifies release signatures; Windows Authenticode publisher signing is not yet configured.
